Chapter 1 · The 5 words

The 5 words: model, harness, session, repository and GitHub

26 November 2026

Claude Code clicked for me once I knew five words. Here they are in plain language, with a horse to help them stick.

In short

  • What: the five words you need before Claude Code makes sense: model, harness, session, repository and GitHub.
  • Big idea: the model thinks, the harness lets it act, and the repository remembers what each session forgets.
  • No code needed: I do most of this from my phone, so if I can follow it, you can too.

Start here

When I first opened Claude Code, words like “harness” and “repo” came at me fast, as if everyone already knew them. It turns out you only need five, and once they’re in place, everything else gets much easier to follow. You don’t need to know how to code.

An unofficial guide, not made by or affiliated with Anthropic.

1. The model: the horse

The model is the AI brain. It reads your message, thinks, and writes an answer. In Claude Code, the model is Claude.

Picture a strong, clever horse. It can do a lot, but on its own it can’t open a file or run a command. It also has no memory between conversations, and it can be wrong, so you still check its work.

2. The harness: the gear that gives the horse hands

The harness is the program around the model that lets it do real things. Claude Code is the harness. It gives the model tools: reading and writing files, running commands, searching a folder.

The harness also decides what the model is allowed to do, and that’s where safety lives. I have a small guard hook in my setup: a piece of code the harness runs before risky actions, which blocks them. The model can’t talk its way past it, because it’s code, not a request.

3. The session: one ride

A session is one conversation with Claude Code. In the cloud version, each session also gets its own temporary computer to work on.

When a session ends, the model forgets it. The next one starts fresh, with no memory of what you said before.

4. The repository: a folder that remembers

A repository (or “repo”) is a folder of files that keeps its full history. Every saved change is kept, so you can see what changed and go back.

This is how you fix the forgetting. Put your rules and notes in a repository, and every new session reads them at the start. I keep a private one for my rules, plans and notes, so Claude behaves the same way every time.

5. GitHub: where repositories live

GitHub is a website that stores repositories online. It keeps them safe, keeps their history, and lets you look at every change before you accept it. Claude Code on the web opens a repository from GitHub at the start of a session, then saves its work back there.

How the 5 words fit together

 YOU  (phone or laptop)
   │  type a message
   ▼
 SESSION  ← one conversation, then it forgets
   ├─ MODEL    Claude       ← the horse: the brain
   ├─ HARNESS  Claude Code  ← the gear: tools, files, commands
   │    └─ GUARD HOOK       ← blocks risky actions
   └─ opens a REPOSITORY    ← the folder that remembers
                 │
                 ▼
             GITHUB         ← where repositories live

You talk to a session. Inside it, the model thinks and the harness acts. The session opens a repository that lives on GitHub, so your work survives after the session is gone.

My mistake

In my first sessions, I’d start a new chat and carry on as if Claude remembered yesterday. It didn’t, so I found myself explaining the same things again and again.

The rule it gave me: If something matters, save it in a file in the repository before the session ends.

Try it yourself

Open Claude Code, start a session, and ask:

In one sentence each, what are the model, the harness and the repository in this session?

Then start a new session and ask what you talked about last time. It won’t know. That moment is the whole reason the repository matters.
